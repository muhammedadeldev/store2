# منصة L'ÉTOILE Haute Couture & Fashion E-Commerce

منصة تجارة إلكترونية متكاملة واحترافية (Production-Ready) مخصصة لبراند أزياء وملابس فاخرة، مبنية بأحدث معايير الويب بدون أي إطارات عمل ثقيلة (Pure Vanilla JavaScript ES6+ Modules, HTML5, CSS3 Variables, Firebase Modular SDK & Node Express Backend).

---

## 1. المميزات والخصائص الرئيسية

### واجهة المتجر الإلكتروني (Customer Storefront)
- **تصميم أزياء راقٍ (Editorial Luxury Fashion UI):** تيبوغرافي فاخر ومدروس مع هوية بصرية مستوحاة من كبرى دور الأزياء الباريسية والإيطالية.
- **دعم كامل للغتين العربية والإنجليزية (Bilingual RTL/LTR):** تبديل فوري وسلس بين الواجهة العربية (RTL) والإنجليزية (LTR).
- **إدارة المتغيرات المتعددة (Multi-Variant Matrix):** لكل قطعة مقاسات وألوان مستقلة مع كود SKU خاص ومخزون دقيق لكل تركيبة.
- **صفحة تفاصيل المنتج التفاعلية (Product Details):**
  - معرض صور متعددة مع تكبير عدسة تفاعلي (Zoom Lens).
  - محدد ألوان ومقاسات مباشر مع تنبيهات لحظية لحالة المخزون (In Stock / Only 2 left / Sold out).
  - دليل مقاسات تفاعلي (Interactive Size & Fit Guide) بالمعايير الفرنسية والإيطالية والسنتيمتر.
  - إرشادات خامات الكشمير والحرير والعناية.
  - نظام تقييمات العملاء مع تمييز الشراء المؤكد وإمكانية إضافة تقييم جديد.
  - قائمة بالقطع المتناسقة والمشابهة.
- **سلة التسوق المتطورة (Shopping Bag Drawer & Page):**
  - سلة جانبية منزلقة مع حساب فوري لشريط الشحن المجاني التفاعلي.
  - تعديل الكميات وحذف القطع مع حفظ الحالة في LocalStorage ومزامنة الحساب.
  - تطبيق كوبونات الخصم والتحقق منها على السيرفر.
- **إتمام الطلب السلس والآمن (Secure Checkout):**
  - اختيار مناطق الشحن التفاعلية مع حساب تكلفة التوصيل ووقت الوصول المتوقع.
  - دعم الدفع عند الاستلام (Cash on Delivery) والبطاقات الائتمانية والمحافظ الرقمية.
  - شاشة تأكيد الطلب الفاخرة مع كود التتبع وزر طباعة الفاتورة الفورية (Print Invoice).
- **حساب العميل (Client Account Portal):**
  - تسجيل الدخول وإنشاء الحساب مع دعم المصادقة بنقرة واحدة عبر Google.
  - سجل الطلبات ومتابعة الحالات.
  - نظام تقديم طلبات الإرجاع والاستبدال (Return & Exchange Request).
  - قائمة المفضلة (Curated Wishlist).
- **التتبع المباشر للطلبات (White-Glove Order Tracking):**
  - شاشة تتبع عامة برقم الطلب مع مراحل التجهيز والشحن ورقم بوليصة الشحن الجوي.

### لوحة التحكم الإدارية (Admin Dashboard)
- **Overview & KPIs:** إجمالي المبيعات، مبيعات اليوم، عدد الطلبات، متوسط قيمة الطلب (AOV)، تنبيهات انخفاض المخزون، وجدول أحدث الطلبات.
- **إدارة المنتجات (Products Management):** إضافة، تعديل، حذف، تحديد الأسعار والخصومات، وإدارة مصفوفة الألوان والمقاسات والـ SKU ومخزون كل Variant.
- **إدارة التصنيفات (Categories):** تصنيفات المعاطف، فساتين السهرة، البدلات، الكشمير، والإكسسوارات.
- **إدارة المخزون (Inventory Management):** سجل حركة المخزون الكامل (Inventory Movements Ledger) مع تتبع كل عملية بيع، إرجاع، تسوية يدوية، أو إلغاء طلب.
- **إدارة دورة حياة الطلبات (Orders Lifecycle):** تغيير الحالة (New, Confirmed, Processing, Packed, Shipped, Delivered, Cancelled) مع إعادة المخزون تلقائياً عند الإلغاء، وإضافة رقم البوليصة والملاحظات وطباعة الفاتورة.
- **إدارة المرتجعات والاستبدال (Returns & Exchanges):** استقبال طلبات العملاء، فحص حالة القطعة المرتجعة، الموافقة أو الرفض، واختيار إعادة القطعة للمخزون أو إهلاكها.
- **إدارة الكوبونات (Coupons):** إنشاء كوبونات بخصم نسبي أو مبلغ ثابت، والحد الأدنى للطلب، وتاريخ الانتهاء، وحد الاستخدام.
- **نظام إدارة المحتوى (CMS):** تعديل نصوص وصور البانر الرئيسي (Hero)، شريط الإعلانات العلوي، معلومات البراند، رقم واتساب المساعد الشخصي، ونسبة الضريبة والشحن المجاني.
- **إدارة الشحن (Shipping Zones):** تحديد المناطق والمحافظات وأسعار التوصيل والمدة المتوقعة لكل منطقة.
- **مراجعة التقييمات (Reviews):** اعتماد أو حذف تقييمات العملاء.

## 2. بنية قاعدة البيانات (Firestore Database Architecture)

- `/products/{productId}`: وثائق المنتجات والمقاسات والألوان ومصفوفة الـ Variants.
- `/categories/{categoryId}`: تصنيفات المتجر.
- `/orders/{orderId}`: طلبات العملاء وسجل الحالات وتفاصيل العناوين والمنتجات.
- `/inventoryMovements/{movementId}`: سجل غير قابل للتعديل لكل حركة دخول وخروج من المخزون.
- `/returns/{returnId}`: طلبات الاسترجاع والاستبدال المقدمة من العملاء وحالة الفحص.
- `/coupons/{couponId}`: رموز الخصم وشروطها ونسبها.
- `/reviews/{reviewId}`: تقييمات العملاء المعتمدة.
- `/settings/{settingsId}`: الإعدادات العامة والمتغيرات الخاصة بالبراند.
- `/shippingZones/{zoneId}`: مناطق الشحن والأسعار وتقدير مدة التوصيل.
- `/admins/{adminId}`: الحسابات الإدارية والصلاحيات (تم تسجيل `mohamedqwe542@gmail.com` كـ Super Admin).

## 3. العمليات الحساسة على السيرفر (Server-Side Security & APIs)

لحماية العمليات التجارية من التلاعب من قبل المتصفح:
- `POST /api/checkout`: يعيد التحقق من أسعار المنتجات وصحة الكوبونات وتوافر المخزون لكل Variant من قاعدة البيانات مباشرة، ويحجز المخزون ويسجل حركة بيع في `inventoryMovements`.
- `POST /api/coupons/validate`: يتحقق من كود الكوبون وتاريخ صلاحيته والحد الأدنى للطلب.
- `POST /api/orders/update-status`: يقوم بتحديث حالة الطلب، وفي حال الإلغاء يعيد الكميات تلقائياً للمخزون ويسجل حركة `cancellation_restock`.
- `POST /api/seed`: زر لتوليد وتجهيز كامل المتجر بالكتالوج الفاخر والصور والتصنيفات والكوبونات بنقرة واحدة.

## 4. التشغيل محلياً (Local Development)

```bash

npm install

# تشغيل خادم التطوير الشامل (Express + Vite) على المنفذ 3000
npm run dev

# بناء النسخة الإنتاجية
npm run build

# تشغيل الخادم الإنتاجي
npm start
```
